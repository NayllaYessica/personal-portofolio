# Portofolio Naylla Yessica Putri

Portofolio statis berbasis HTML, CSS, dan JavaScript tanpa framework atau proses build.

## Struktur

- `index.html` — konten, profil, proyek, dan tautan.
- `css/style.css` — tampilan responsif, tema terang/gelap, dan palet pastel.
- `js/main.js` — pergantian tema dan warna, menu mobile, filter proyek, animasi, dan tahun otomatis.
- `assets/images/` — tempat foto profil dan gambar proyek jika sudah tersedia.

## Jalankan lokal

Buka `index.html` langsung, atau gunakan ekstensi Live Server di VS Code untuk melihat perubahan saat dikembangkan.

## Yang sebaiknya dilengkapi berikutnya

1. Ganti ilustrasi inisial pada hero dengan foto profil pilihan sendiri; simpan gambar di `assets/images/` dan gunakan teks alternatif yang sesuai.
2. Tambahkan tautan demo, repositori, atau studi kasus pada setiap proyek. Lengkapi peran, tahun, masalah yang diselesaikan, kontribusi, dan hasilnya.
3. Pastikan kategori serta teknologi proyek akurat. Beberapa detail, seperti teknologi SafeLab dan tujuan proyek Reviewers, masih perlu diverifikasi.
4. Tambahkan URL LinkedIn bila ingin ditampilkan, serta email profesional bila ingin menyediakan jalur kontak selain WhatsApp.
5. Pilih beberapa tulisan blog unggulan dengan judul, tanggal, ringkasan, dan tautan langsung.
6. Perbarui deskripsi media sosial dan metadata situs setelah domain publik tersedia.

## Deploy ke GitHub Pages

1. Unggah isi folder ini ke repository GitHub.
2. Buka **Settings → Pages**.
3. Pada **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Setelah halaman tersedia, uji navigasi, filter proyek, tema, dan tautan kontak dari desktop maupun ponsel.

Pengunjung dapat memilih palet **Sage**, **Rose**, **Lavender**, atau **Sky** dari ikon warna di bagian atas. Tema terang/gelap dan palet warna disimpan secara terpisah di browser.

Situs ini sengaja dibuat tanpa framework agar kontennya mudah diperbarui. Jika kebutuhan berkembang, struktur proyek dapat dipindahkan ke generator situs statis atau CMS.
