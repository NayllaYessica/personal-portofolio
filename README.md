# Naylla Yessica Putri — Portfolio

## Struktur
- index.html      : isi/struktur halaman
- css/style.css   : tampilan (warna ada di bagian :root)
- js/main.js      : dark mode, menu mobile, animasi, tahun footer
- assets/images/  : taruh profile.jpg dan thumbnail proyek di sini

## Jalankan lokal
Klik dua kali index.html, atau di VS Code pasang ekstensi "Live Server" lalu "Go Live".

## Deploy ke GitHub Pages
1. Buat repository publik di GitHub (mis. `portfolio`), upload semua isi folder ini.
2. Buka Settings > Pages.
3. Source: "Deploy from a branch", pilih branch `main` dan folder `/ (root)`, lalu Save.
4. Tunggu 1-2 menit; alamatnya https://NayllaYessica.github.io/portfolio/
5. Uji dari HP: navigasi, dark mode, dan tombol WhatsApp.
