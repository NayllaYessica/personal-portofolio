01 / Tentang saya

Rasa ingin tahu adalah titik awal.

Saya Naylla, mahasiswa D3 Teknologi Informasi di Politeknik Negeri Madiun. Ketertarikan saya pada teknologi dimulai dari rasa penasaran: bagaimana sebuah halaman web bisa tampil, bergerak, dan menyimpan data?

Saat ini saya fokus belajar web development dan mulai mengenal dunia data. Saya suka membangun hal kecil yang berfungsi, lalu memperbaikinya sedikit demi sedikit.

Di luar layar, saya membaca dan menulis. Membaca memberi saya sudut pandang baru, sedangkan menulis membantu merapikan pikiran. Alam menjadi tempat saya mengambil jeda.
